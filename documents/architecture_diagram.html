Dynamic Menu & Live Stock Service /menu
Session-Isolated Cart Engine /add_to_cart
Order & Inventory Deduction Controller /generate_bill
Dynamic UPI QR Code Generator /upi_qr (qrcode + PIL)

🗄 Relational Database Schema SQLAlchemy Models
products Inventory Table
[PK] id: Integer
name: String(100)
category: String(50)
price: Float
stock: Integer
available: Boolean
orders Billing Header
[PK] id: Integer
bill_no: String(50)
customer_name: String(100)
total: Float
payment_method: String
payment_status: String
order_date: String (Date & Time)
order_items Order Line Items
[PK] id: Integer
[FK] order_id: Integer
product_name: String
quantity: Integer
price: Float
amount: Float
🗃️
SQLite Database
canteen.db
Lightweight serverless SQL engine managed via SQLAlchemy ORM. Stores real-time product stock, order records, and transaction histories.
